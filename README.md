## ✨ 核心特色与技术栈

* **视觉与风格**：赛博朋克 / 终端控制台（Terminal & Cyberpunk UI）、JetBrains Mono 字体。
* **CSS 框架**：Tailwind CSS (CDN) + 原生精细 CSS 动画。
* **动效设计**：
  * **主页**：Canvas 2D 代码雨矩阵、SVG 粒子数学轨迹流动。
  * **目录页**：自适应多列瀑布流排列（支持手机 1 列、平板 2 列、桌面 3 列、超宽屏 4 列）、500ms 流光骨架屏无缝过渡。
* **架构特点**：纯静态、轻量化、零依赖服务端，全站直接托管于 GitHub Pages。
